## 1. 实验目的

E0 是"最弱但最干净"的 decoder 基线：只读取编码器最后一个 stage 的 `neck` 特征（256×64×64），用一个 1×1 卷积降到单通道，再双线性插值回 1024×1024，**没有任何 norm、激活、跳连或金字塔结构**。

它回答两个问题：

1. 冻结的 MedSAM 特征本身是否已经线性可分（若线性头就能拿到合理 Dice，说明瓶颈不在 decoder）；
2. 作为其他三个 decoder 的下界参考。

## 2. 模型结构

```
neck [B, 256, 64, 64]
  └─ Conv2d(256 → 1, kernel=1, stride=1, padding=0)   # 257 参数（256 权重 + 1 偏置）
     └─ F.interpolate(mode='bilinear', align_corners=False, size=1024)
        └─ logits [B, 1, 1024, 1024]
```

可训练参数仅 257 个，其中 256 个是通道加权系数。整个模型没有任何空间可学习的算子——**空间结构完全依赖冻结的 ViT 特征**。这是四组实验中参数量的极端下界。

checkpoint 中仅保存 2 个张量（该卷积的权重与偏置），文件大小 8.7 KB。

## 5. 曲线解读

### 5.1 前四个 epoch：几乎不预测任何阳性

初始时 recall ≈ 0.0003（491 个阳性切片里只蒙对不到 1 个），`all-Dice` 却高达 0.9166。这个"高 all-Dice"完全是伪象：模型几乎输出全阴，6123 个阴性切片中绝大多数是"空 GT + 空预测"，按评估规则得 Dice 1.0，从而把平均值抬到 0.91。参见 [protocol.md](protocol.md) 第 6 节。

### 5.2 epoch 6–12：从一个极端滑向另一个极端

模型开始输出阳性后行为迅速反转：

- FP-slice rate 从 0.147（ep6）飙到 0.752（ep12）；
- recall 从 0.020 升到 0.378；
- `all-Dice` 从 0.79 崩到 0.25（阴性切片全部被判阳性，Dice 归零）。

这不是"学会分割"，而是模型发现了一个更省力的解——**把大片区域标为阳性**——因为：
- Dice 损失对假阳性与假阴性对称，而在 1:1 的正负片采样下，标大面积可以在阳性切片上快速降低损失；
- 1×1 卷积没有任何空间约束，输出的空间形态完全由冻结特征决定，无法精细收缩边界；
- 阈值固定 0.5，且无后处理。

### 5.3 epoch 12–40：平台期但未过拟合

与 E1/E2/E3 不同，E0 的验证损失**全程单调下降**（1.2422 → 0.9894），train_loss 也持续下降（1.4065 → 0.9043），没有出现训练/验证背离。pos-Dice 在 epoch 24 后进入缓慢平台（0.3317 → 0.3355，最后 16 个 epoch 只涨 0.4 个百分点）。

这说明：257 参数的线性头**既没有容量去拟合训练集（不存在过拟合），也没有能力突破当前解**。它稳定停在一个"大面积预测"的折中点：recall 0.4688，precision 0.0632。

## 6. 异常与事件

- epoch 40 出现 1 次"梯度非有限，跳过该步"告警，全程共 14 次（分布在 epoch 9/12/14/17/19/21/24/26/28/31 等），未导致训练中断。
- checkpoint 不含 encoder 权重（`note` 字段说明需从 `weights/medsam_vit_b.pth` 恢复）。

## 7. 结论

1. E0 证明了**冻结 MedSAM 特征是可线性读取的**：257 个参数就能达到 pos-Dice 0.3355、recall 0.469，显著高于随机水平，说明 `neck` 特征中已经包含病灶位置信息。
2. 但线性头无法把"响应区域"收缩到病灶尺度，precision 仅 0.063，说明**空间精修必须由 decoder 完成**，这为 E1–E3 的存在提供了依据。
3. E0 的最佳点在最后一轮、且未饱和，若继续训练 pos-Dice 大概率还会缓慢上升（代价是 FP rate 继续恶化），但这不是有价值的改进方向。
4. E0 的失败模式（早期全阴 → 后期大面积预测）与 E1/E2/E3 的"初始即全阳性"不同，说明**模型初始化的输出偏置**决定了训练早期的行为，而 40 个 epoch 的所有模型都收敛到"偏阳性"的解上。
