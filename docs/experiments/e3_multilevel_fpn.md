## 1. 实验目的

E3 是 Phase 1 中设计上最完整的 baseline：它同时使用 **ViT 的三个中间层特征（f3/f6/f9）+ neck**，在 decoder 内构造 P2–P5 金字塔并做 top-down FPN 融合，输出头与 E1 完全一致。

它回答的问题：把 E1 的"金字塔结构"和 E2 的"多级 ViT 特征"结合起来，能否取得四组中的最佳结果？

## 2. 模型结构

```
f3, f6, f9 (各 [B, 768, 64, 64])  +  neck [B, 256, 64, 64]
  ├─ Conv1x1(768 → 128) ×3        +  Conv1x1(256 → 128)          # 四级统一到 128 通道
  ├─ P2 = f3 → 转置卷积 ×2 两次 → 256×256    （最浅层特征，最高分辨率）
  ├─ P3 = f6 → 转置卷积 ×1 → 128×128
  ├─ P4 = f9 → 1×1 投影，保持 64×64
  └─ P5 = neck → 1×1 投影 + Conv3x3(stride=2) → 32×32
     top-down: D5 = P5
               D4 = Smooth(P4 + nearest_up(D5))
               D3 = Smooth(P3 + nearest_up(D4))
               D2 = Smooth(P2 + nearest_up(D3))                    # Smooth = Conv3x3 + GN + GELU
  └─ TwoStageSegHead(upsample_factor=4)   # 与 E1 完全相同
       → logits [B, 1, 1024, 1024]
```

与 E1 的唯一差别是**金字塔每一层的特征来源**：E1 全部由 `neck` 自上而下派生，E3 则由四级编码器特征直接提供。

checkpoint 保存 40 个张量（最多），文件 14.6 MB。

## 5. 曲线解读

### 5.1 epoch 1：全阳性起点 + 四组最高起始召回

第一轮 FP-slice rate **0.9974**（6123 个阴性切片中 6107 个被判阳性），recall 高达 0.8466，但 `all-Dice` 只有 0.0296。与 E1 的起点几乎一致（E1：0.9891 / 0.6043 / 0.0375）——**同为"neck + 自建金字塔"的组合，E1 与 E3 的初始行为高度相似**，暗示初始的全阳性倾向来自 `neck` 特征与输出头初始化，而非某个特定 decoder。

### 5.2 峰值（epoch 6）：高召回、高假阳性

- recall 0.7136（覆盖了近 3/4 的病灶像素）
- precision 0.1189
- FP-slice rate 0.9267

也就是说，峰值性能的实现方式是"几乎到处都标"，主指标 pos-Dice 完全奖励了这种行为。

### 5.3 epoch 6 → 40：同样的收缩过程，衰退幅度 0.153

| 指标 | ep6 | ep40 | 变化 |
| --- | ---: | ---: | --- |
| pos-Dice | 0.4824 | 0.3295 | −0.153（−31.7%） |
| precision | 0.1189 | 0.3327 | +0.214 |
| FP-slice rate | 0.9267 | 0.5309 | −0.396 |
| recall | 0.7136 | 0.4292 | −0.284 |
| all-Dice | 0.1037 | 0.4587 | +0.355 |
| val_loss | 0.9771 | 0.9814 | +0.0043 |

训练损失从 0.785 降到 0.547（−30%），验证损失在 epoch 6–10 触底后回升，过拟合形态与 E1/E2 一致。

值得注意的是 E3 的**衰退幅度（31.7%）比 E1（25.5%）更大**，而且它的峰值也是四组最高——即"峰值越高，后期落差越大"，说明模型在 epoch 6 之后一直在优化一个与主指标冲突的方向（降低假阳性），而主指标并不认可。

## 6. 异常与事件

- 全程 14 次"梯度非有限，跳过该步"告警，含 epoch 5/6/7 连续三轮出现。
- 由 `scripts/run_training_sequence.sh` 启动（E2 完成后紧接着启动，两个实验之间仅隔 6 秒）。
- 结束时间 2026-09-26 01:43:59，是 Phase 1 四组实验中最后一个完成的。

## 7. 结论

1. **E3 是 Phase 1 的最佳结构**：pos-Dice 0.4824、pos-IoU 0.3711、峰值 recall 0.7136 均为四组第一，验证了"多级 ViT 特征 + 金字塔 FPN"的设计假设。
2. 但相对 E2 的优势很小（pos-Dice +0.0074，recall +0.0769，precision −0.0291），**没有统计意义上的明显领先**（单一 fold、单一 seed、无重复实验，无法判断该差距是否超过噪声）。
3. E3 的算力代价最高（6.17 h，训练与验证均为四组最慢/次慢），单位收益比不如 E2。
4. 与 E1 共享同一个输出头、同为"neck 派生金字塔"的起点行为，但峰值高出 0.036，说明**四级特征的引入比金字塔深度更重要**——这与 E2 vs E1 的对比结论一致。

## 8. 改进建议（针对 E3）

1. E3 是后续调优的主线候选：优先在此结构上做阈值扫描、后处理、损失改造。
2. `val_interval=2` 使峰值位置不确定（epoch 6 前后），建议用 `val_interval=1` 在 epoch 3–12 区间密集验证以定位真实最优。
3. 建议做消融：去掉 `neck`（只留 f3/f6/f9）或去掉某一级 ViT 特征，判断 FPN 各层的贡献。
4. 若要跑多折（fold1–4）以确认 E3 > E2 的结论，需要 4 倍机时（约 25 h/实验），建议先完成 P0 级改进后再做。
