## 1. 实验目的

E2 换掉了特征来源：不再使用 `neck`，而是取 ViT 主干的**四个中间 block 输出**（block 3/6/9/12 → `f3/f6/f9/f12`，各 768×64×64），按 UNETR 的方式从最深特征逐级上采样、与浅层特征拼接融合。

它回答的问题：**ViT 中间层的多级跳连**（而非 neck 的单层特征）能否带来更好的边界与更少的假阳性？

## 2. 模型结构

```
f3, f6, f9, f12  (各 [B, 768, 64, 64])
  ├─ Conv1x1(768 → 128) ×4                     # 每级投影
  └─ 自深向浅逐级融合（f12 → f9 → f6 → f3）:
        up = F.interpolate(bilinear, size=下一级)
        x  = Conv3x3(concat([up, f_i]) → 128) + GN + GELU     # _FuseBlock
  └─ ×2 双线性上采样 → 1024×1024
  └─ _RefineBlock: Conv3x3 + GN + GELU
  └─ TwoStageSegHead(upsample_factor=1):
       3x3 Conv(128→64) + GN + GELU → 3x3 Conv(64→32) + GN + GELU → 1x1 Conv(32→1)
       → logits [B, 1, 1024, 1024]
```

特点：

- 四级特征全部来自 ViT 编码器，**没有自建金字塔**；
- 融合只用 concat + 3×3 卷积，**无注意力、无 gating**（名字中的 UNETR 仅指"ViT 特征 + U 形逐级融合"这一范式）；
- 所有 ViT 特征分辨率相同（64×64），所谓的"多级"是**深度方向**的多级，不是分辨率方向的多级——上采样只发生在最后 ×2 到 1024（`upsample_factor=1` 意味着输出头内部不做额外放大）。

checkpoint 保存 28 个张量，文件 18.3 MB。

## 5. 曲线解读

### 5.1 epoch 1–6：高召回 + 中度假阳性，峰值提前出现

与 E1/E3 的"全阳性"起点不同，E2 第一轮的 FP-slice rate 只有 0.5817（其余两者 0.99），`all-Dice` 达到 0.4139。这说明**多级 ViT 特征的初始响应更"挑食"**，不会无差别地把整张切片标成阳性——四级深层特征的语义判别性明显优于单个 `neck`。

峰值（epoch 6）pos-Dice 0.4750，是 E0/E1 之后的最高值，同时 recall 0.6367、precision 0.1480。

### 5.2 epoch 12 之后：唯一一条"反向漂移"曲线

E2 是四组实验中唯一在后期**显著改善全局分割质量**的模型：

| 指标 | ep6 | ep24 | ep40 |
| --- | ---: | ---: | ---: |
| pos-Dice | 0.4750 | 0.3454 | 0.3107 |
| all-Dice | 0.2481 | 0.6339 | 0.6785 |
| precision | 0.1480 | 0.4026 | 0.4869 |
| recall | 0.6367 | 0.4392 | 0.4066 |
| FP-slice rate | 0.7700 | 0.3430 | 0.2920 |

即：假阳性减少了一半以上，precision 提升 3.3 倍，负片上的分割正确率显著提高；代价是主指标 pos-Dice 掉了 0.164。

把这个现象与 E1/E3 对比可以看出一个一致的规律：**模型在训练后期都在做"收缩预测区域"的工作**（E1 precision 0.09→0.27，E3 0.12→0.33，E2 0.15→0.49），而只要主指标是不惩罚假阳性的 pos-Dice，这个收缩过程就必然表现为指标退化。E2 只是把这件事做到了最彻底。

### 5.3 训练/验证背离

- train_loss：1.2662 → 0.5421（−57%）
- val_loss：最低 0.9733（epoch 8），随后回升到 0.9830
- pos-Dice：epoch 6 起持续下降

典型的过拟合。可训练参数 1.52 M 在 27090 张切片（其中仅 1844 张阳性）上仍然过拟合，且比 E1/E3 更早（epoch 6 即达峰）。

## 7. 结论

1. **ViT 中间层多级特征优于单层 neck 特征**：E2 峰值 0.4750 vs E1 0.4461 / E0 0.3355，且初始行为明显更"理智"（FP rate 0.58 而非 0.99），说明深层-浅层特征的语义互补是关键增益来源。
2. E2 的峰值（epoch 6）是四组中最早的，说明**可训练参数越多、收敛越快也越早过拟合**（E2 1.52 M > E3 1.21 M > E1 1.06 M，峰值 epoch 6 / 6 / 8）。
3. E2 在 epoch 24–40 达到"低假阳性"状态（FP rate 0.29、precision 0.49），这是四组实验中最接近可用于后处理的状态。**若配合阈值扫描与后处理，这个阶段的 checkpoint 可能比 epoch 6 的 best 更有实用价值**——但这一点需要 `evaluate.py` 的 volume 级评估来验证。
4. 训练总时长为四组最短（5.33 h），因为不需要自建高分辨率金字塔。

## 8. 改进建议（针对 E2）

1. 对 `checkpoint_latest.pth`（epoch 40）与 `checkpoint_best.pth`（epoch 6）分别做完整评估与阈值扫描，量化"高召回/低假阳性"两种解的实用性差异。
2. 加入 gating 或注意力融合（当前是纯 concat + 3×3 卷积），或引入分辨率方向的真实多尺度（如把 f12 再下采样一级）以改善小病灶定位。
3. 由于峰值过早，建议缩短训练或加早停；同时评估解冻最后 1–2 个 ViT block 是否能突破 0.48 的天花板。
