## 1. 研究问题

Phase 1 的核心问题：

> 在 **MedSAM ViT-B 图像编码器完全冻结** 的前提下，仅训练轻量 decoder，能够在前列腺 T2W MRI 上完成临床显著前列腺癌（csPCa）病灶的切片级分割吗？不同 decoder 结构（单尺度线性头 / 单尺度金字塔 / 多级 UNETR 式 / 多层级 FPN）之间的差距有多大？

四组实验共享同一编码器、同一数据划分、同一损失与优化配置，**唯一变量是 decoder 结构及其读取的编码器特征层级**。

## 2. 实验设计

| 维度 | E0 | E1 | E2 | E3 |
| --- | --- | --- | --- | --- |
| decoder | `LinearHead`（1×1 conv + 双线性上采样） | `SimplePyramid` + FPN | `UNETRStyleDecoder` | `MultiLevelFPN` |
| 读取的编码器特征 | `neck`（256ch，单层） | `neck`（256ch，单层） | `f3/f6/f9/f12`（768ch，四级） | `f3/f6/f9/neck`（四级，含 neck） |
| 跳连层级 | 无 | 无（单尺度自建金字塔 P2–P5） | 四级 ViT 特征 | 四级混合特征 |
| 上采样方式 | 双线性到 1024 | 转置卷积 + nearest 融合 | 双线性 + concat + 3×3 conv | 转置卷积 + nearest FPN 融合 |
| 可训练参数 | **257** | **1,061,601** | **1,519,329** | **1,209,185** |
| 输出分辨率 | 1024×1024 | 1024×1024 | 1024×1024 | 1024×1024 |

编码器固定为官方 MedSAM ViT-B（`weights/medsam_vit_b.pth`，89,670,912 参数，全部冻结，`trainable=0` 已由前置检查与训练日志双重确认）。四组实验的**总参数量均为 90.7–91.2 M，差异只体现在 decoder 的 0.26 K – 1.52 M 上**。

## 4. 关键发现

### 4.1 decoder 结构有影响，但差距远小于预期

最佳正片 Dice 排序为 **E3 (0.4824) > E2 (0.4750) > E1 (0.4461) > E0 (0.3355)**，多层级特征融合（E3）优于单尺度（E0/E1），但 E2 与 E3 之间仅差 0.007，E1 与 E3 相差 0.036。考虑到 E0 仅有 257 个参数却达到 0.3355，**decoder 容量不是当前主要瓶颈**。

### 4.2 所有模型在训练早期（epoch 6–8）即达到峰值，随后持续退化

E1/E2/E3 的最佳 checkpoint 分别出现在 epoch 8 / 6 / 6，此后正片 Dice 单调或波动下降 10–17 个百分点（E3：0.4824 → 0.3295）。训练损失继续下降（E3：0.785 → 0.547），验证损失在 epoch 6–8 后止降回升，是典型的过拟合信号；同时验证指标下降伴随着预测行为改变（见 4.3）。

> 注意：`val_interval=2` 使早期只有 epoch 1/2/4/6/8 五个验证点，真实峰值可能被采样间隔掩盖，epoch 6 附近的实际最优尚未被精确定位。

### 4.3 主要失败模式是"假阳性爆炸"，而非漏检

最佳 epoch 时阳性切片召回率已达 0.64–0.71，但：

- precision 仅 **0.06–0.15**（E0 最低 0.063）；
- 阴性切片被误判为阳性的比例高达 **77%–99%**（E1 为 99.15%）。

即模型倾向于"几乎在所有切片上都画出病灶"，把病灶区域画得远大于真实病灶。E0 早期（epoch 1–4）则相反，几乎不预测任何阳性（recall ≈ 0.0003），随后缓慢滑向"全阳性"（epoch 40 recall 0.4688，all-Dice 从 0.9166 崩到 0.2012）。四个模型最终都处在"偏阳性"的解上。

### 4.4 `all-Dice` 的高低不能直接解读为性能好坏

评估实现中，**GT 为空且预测也为空时 Dice 记为 1.0**（见 `src/metrics/segmentation.py`）。因此：

- E0 早期几乎不预测任何阳性，负片全部"空对空"得 1.0，`all-Dice` 虚高到 0.9166；
- E1/E3 早期预测全阳性，负片 Dice 全为 0，`all-Dice` 只有 0.03–0.04；
- E2 后期假阳性被抑制，`all-Dice` 回升到 0.68。

解读 `all-Dice` 必须与 `FP-slice rate`、precision 联合看，论文主指标应使用 `pos-Dice`。

### 4.5 极端类别不平衡是核心约束

| 统计项 | train（fold1–4） | val（fold0） |
| --- | ---: | ---: |
| 切片总数 | 27,090 | 6,614 |
| 阳性切片 | 1,844（6.81%） | 491（7.42%） |
| 阳性切片病灶像素中位数 | 655 px | 562 px |
| 中位病灶占整图面积比 | **0.062%** | 0.054% |
| 数据集级正像素占比 | **0.0091%** | 0.0109% |

即：正像素占比约 1/11000，且阳性切片中位病灶只有约 26×26 像素大小。在 1024×1024 输入、固定阈值 0.5、无后处理、BCE 无 `pos_weight` 的设置下，网络输出大面积假阳性几乎是必然结果。

### 4.6 验证开销接近训练开销的一半

| 实验 | 平均训练/epoch | 平均验证/次 | 验证总时长占比 |
| --- | ---: | ---: | ---: |
| E0 | 218.2 s | 511.6 s | 55% |
| E1 | 284.3 s | 499.8 s | 48% |
| E2 | 228.5 s | 479.0 s | 52% |
| E3 | 284.9 s | 515.4 s | 49% |

E1/E3 单 epoch 训练时间比 E0/E2 长约 25%，与其在 1024² 分辨率上的转置卷积/高分辨率卷积开销一致。验证集全量 6614 切片每 2 epoch 评估一次，是四组实验中最大的固定成本。

### 4.7 数值稳定性存在隐患

四组实验在训练过程中均出现"梯度非有限，跳过该步"的告警：E0 14 次、E1 15 次、E2 13 次、E3 14 次（fp16 AMP + GradScaler 已启用）。单步跳过未影响训练连续性，但说明 fp16 下存在数值风险，建议改用 bf16 或对损失/梯度做更严格的处理。

### 4.8 尚未完成的部分

- `evaluate.py` **尚未执行**：目前所有报告数字均为训练期切片级指标，没有 volume 级预测、没有 per-case 指标、没有阈值扫描。
- 未做任何后处理（最大连通域、最小体积过滤、切片间一致性）。
- 未使用 ADC/HBV 序列（`input_mode: t2_repeat`，T2W 复制三通道）。
- 输入归一化使用非零区域 0.5/99.5 百分位映射到 [0,1]，**未采用 MedSAM/SAM 官方 `pixel_mean`/`pixel_std` 归一化**，与预训练分布存在域偏移风险（尚未做消融验证）。

## 5. 结论与下一步

Phase 1 的结论是：

1. 冻结 MedSAM 编码器 + 轻量 decoder 的路线**可以训起来且能定位病灶**（正片 Dice 0.44–0.48，召回 0.64–0.71），多层级特征融合（E3）是最优结构；
2. 但当前性能被**假阳性**和**早期过拟合**严重限制，瓶颈不在 decoder 容量；
3. 现有实验协议中，**阈值、后处理、损失设计、归一化** 四个环节都还没有做最基本的处理，属于"未调优基线"。

下一步优先级建议（按预期收益排序）：

| 优先级 | 动作 | 依据 |
| --- | --- | --- |
| P0 | 运行 `evaluate.py` 做 volume 级 + per-case 评估，并做阈值扫描 | 现有数字全部是训练期切片指标，无法判断真实病灶检出水平 |
| P0 | 加入后处理（最小体积过滤 + 最大连通域） | precision 0.06–0.15，预测面积远超病灶 |
| P0 | 定位真实峰值：`val_interval=1` 重跑 E3，或从 `checkpoint_latest` 的 epoch 4–12 做回放评估 | best 出现在 epoch 6，峰值可能被 2-epoch 间隔掩盖 |
| P1 | 损失改造：BCE 加 `pos_weight`，或换 Tversky/Focal，并启用 `DiceBCELoss.components()` 分项日志 | 正像素占比 0.009% |
| P1 | 归一化消融：官方 `pixel_mean/std` vs 现有百分位归一化 | 与 MedSAM 预训练域对齐 |
| P1 | 早停 / 缩短训练至 15–20 epoch，或加强正则（增强仅翻转+旋转±15°+缩放） | 最佳 epoch 6–8，之后 40 轮全部浪费 |
| P2 | 验证集子采样（如按 case 抽 1/3）或加大 `val_interval` | 验证占掉近一半机时 |
| P2 | 数值稳定性：AMP 改 bf16 | 每实验 13–15 次非有限梯度 |
| P2 | 解冻部分编码器（如最后 1–2 个 block 或 LoRA/adapter）作为对照 | 验证"冻结是否本身成为上限" |
